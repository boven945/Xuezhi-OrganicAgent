## 2. 语料的内容依据

### 2.1 课程标准是权威边界

依据《普通高中化学课程标准（2017年版2020年修订）》，有机化学内容
分四个模块，全部纳入：

| 课标模块 | 对应章节 | 条数 |
| --- | --- | --- |
| 有机物的组成与结构 | 第一章 | 4 |
| 烃及其衍生物的性质与应用 | 第二、三章 | 24 |
| 有机合成 | 第六章 | 1 |
| 生物大分子及合成高分子 | 第五章 | 5 |

课标对选修三的具体要求逐条对照：辨识和书写同分异构体、掌握分类与命名、
认识常见官能团及其鉴别方法和相互影响、建立官能团与特征性质的联系、
比较烷烃烯烃炔烃芳香烃的差异、掌握有机合成路线设计方法、
了解绿色化学思想、辨识加聚与缩聚、认识生物大分子组成结构性质用途。

必修部分（乙烯、乙醇、乙酸）一并覆盖，因课标必修主题4
"简单的有机化合物及其应用"也涉及这三者。

### 2.2 版权处理方式

**每条内容都是项目组依据课标要求自行编写的表述，不是教材原文摘录。**
具体做法：

- 用自己的语言组织知识点，而非照抄教材段落
- 交叉参考多个公开网络教学资料核对事实（见 §2.3）
- 全部标记 `license: project-authored`
- 每条带章节级 `locator`，便于定位与复核
- `reviewer` 标记为「待化学教研组审核」——**尚未经专业审核**

> ⚠️ 这一版**未经化学教师审核**。`product-scope.md` §7 要求内容范围
> 与教学口径须由项目负责人批准；知识点的准确性与表述是否符合教学要求，
> 仍须化学教研组确认（H13/H18）。

### 2.3 交叉验证与发现的易错点

多个来源交叉核对时，几处高频易错点被确认并写入语料：

**① 苯酚酸性的相对强弱（多处资料一致）**

苯酚能与 NaOH、Na₂CO₃ 反应，但不与 NaHCO₃ 反应、不放出 CO₂。
据此确定顺序：**碳酸 > 苯酚 > 碳酸氢根离子**。
这个知识点在语料中单独强调，因为「苯酚与碳酸钠反应」是易错点——
常被误认为不放气或生成 Na₂CO₃。

**② 苯使溴水褪色 vs 苯酚使溴水褪色（本质不同）**

- 苯：物理萃取，溴从水层转移到苯层，**不是化学反应**
- 苯酚：化学反应，生成白色三溴苯酚沉淀

这个区分单独成条（`org-arene-extraction-trap`），因为检索时
常被混淆，且直接影响鉴别题的解法。

**③ 醇的催化氧化产物取决于 α 碳上的氢数**

- α 碳有 2 个氢（伯醇）→ 醛（可继续氧化为羧酸）
- α 碳有 1 个氢（仲醇）→ 酮（不能继续催化氧化）
- α 碳无氢（叔醇）→ 不发生催化氧化

**④ 醇与酚的差异是双重的**（不只是酸性）

醇羟基连饱和碳、酚羟基连芳环。除酸性差异外，
酚羟基使苯环邻对位活泼，苯酚与浓溴水即可生成白色沉淀，
而苯的取代必须加催化剂。这点单独成条。

**⑤ 醛与酮的差异根源**

两者都含羰基都能加氢，区别在羰基碳是否连接氢原子：
醛基连接氢故可被弱氧化剂氧化，酮基连接两个碳故不能。
所以丙酮不产生银镜。

## 3. 实测数据（真实 bge-small-zh + chromadb）

33 个检索探针，覆盖烃类、衍生物、实验、高分子、综合五类：

| 指标 | 值 |
| --- | --- |
| 语料条数 | 41（21 个主题） |
| 探针数 | 33 |
| **首位正确** | **27/33（81.8%）** |
| **top3 命中任意** | **32/33（96.97%）** |

### 3.1 失败模式分析：6 个非首位案例的共同特征

| 问 | top1（错） | 目标所在位置 |
| --- | --- | --- |
| 苯的结构有什么特点 | arene-homologue | **top2** |
| 苯的硝化反应条件是什么 | arene-homologue | **top3** |
| 乙酸的酸性有多强 | amino-acid-protein | **top2** |
| 高中有机反应有哪些类型 | required-experiments | **top2** |
| 怎么鉴别羧酸和苯酚 | carboxylic-acid | top2 |
| 官能团有哪些特征反应 | synthesis-strategy | **top2** |

**6 个中有 5 个的正确片段就在 top2 内，只有 1 个完全未命中。**

这个分布说明问题**不是"检索不到"而是"排序不够准"**。
最典型的案例是「乙酸的酸性有多强」命中了 `org-amino-acid-protein`
（蛋白质条目），原因是该条目讲了「氨基酸含氨基和羧基，具有两性」——
在嵌入空间中，"羧基 + 酸性"的语义信号确实很强。

**这正是混合检索 + 重排序要解决的问题**（决策登记表 I1）：
向量检索给出候选集（top3 已含正确答案），reranker 负责重排。
当前没有 reranker，所以正确片段被语义邻居挤到第二位。

### 3.2 阈值仍不起作用（与上轮结论一致）

语料从 6 条增至 41 条后，多阈值对比：

```
thr=None: 命中率=0.9697
thr=0.4: 命中率=0.9697
thr=0.5: 命中率=0.9697
thr=0.6: 命中率=0.9697
thr=0.7: 命中率=0.9697
```

**从 6 条到 41 条，阈值依然完全不起作用。**这说明距离分布的
区分度需要更大样本才显现——**41 条仍属"最小可用集"**。

结论不变：`KnowledgeStore.query` 不设默认阈值，
生产阈值仍待标注问答集实测确定（C5/H18）。
本轮数据进一步支持"须扩充到数百条量级"的判断。

## 4. 测试结果

| 类别 | 结果 |
| --- | --- |
| builder 单元测试 | 20/20（含 7 项语料合规回归保护） |

合规回归保护的价值：**若有人改动语料违反准入要求，测试会失败**。
覆盖：许可标记、审核状态、课程范围、章节定位、文本长度、
课标必需主题覆盖、id 命名规范。

| 项 | 说明 |

| **化学教师审核** | 全部 41 条待审核。知识点的准确性与教学口径须专业确认（H13/H18） |

| **结构化数据（谱图等）** | 课标要求能分析质谱、核磁共振氢谱、红外光谱图谱信息，当前未覆盖 |

## 6. 复现命令

```bash
# 单元测试（无需模型与网络）
docker build -f backend/tests/Dockerfile.test -t xuezhi-chem-test .
docker run --rm xuezhi-chem-test python -m pytest backend/tests/ --no-header

# 有机语料 E2E（需下载 bge 权重，约 400MB；耗时约 4 分钟）
docker run --rm -e XUEZHI_RUN_MODEL_TESTS=1 xuezhi-chem-test \
  python -m pytest backend/tests/knowledge/test_organic_e2e.py -v -s

# 如需把评估结果落盘到宿主机（Git Bash 需禁用路径转换）
export MSYS_NO_PATHCONV=1 MSYS2_ARG_CONV_EXCL="*"
docker run --rm \
  -v "F:/Xuezhi-OrganicAgent/data/eval:/eval" \
  -e XUEZHI_RUN_MODEL_TESTS=1 \
  -e XUEZHI_EVAL_OUTPUT=/eval/organic-retrieval.json \
  xuezhi-chem-test \
  python -m pytest backend/tests/knowledge/test_organic_e2e.py::TestRetrievalRequiresE2E -q -s
```
