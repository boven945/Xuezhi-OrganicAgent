# 安全与隐私基线

## 1. 适用范围

本基线适用于学生浏览器、FastAPI、MCP 工具调度、openPangu 云端 API/本地模型、ChromaDB、RDKit、Fay 和 Edge-TTS 的逻辑链路。系统面向教育场景，输入应视为可能包含未成年人个人信息的敏感内容；默认仅处理完成教学任务所必需的数据。

本文为上线前控制要求，不代表当前仓库已实现或已通过安全评估。

## 2. 数据最小化与保留

- 默认不要求学生提供姓名、学校、联系方式、账号或精确位置。
- 教学问题仅在完成回答和必要诊断所需范围内处理；除非产品明确需要，不建立跨会话画像。
- 日志默认不记录完整原始提问、模型完整提示词、认证头或不必要的个人信息。
- 明确日志、会话、音频和分析数据的保存期限、删除流程、访问角色和数据存储位置后再上线。
- 向华为云 MaaS、Fay 或其他第三方发送数据前，应核实数据处理条款、区域、保留策略和授权，并在用户告知中说明。
- 不默认录制、存储或训练使用学生语音/文本；如未来要做，需单独完成授权、目的限制与删除机制设计。

## 3. 凭据与访问控制

- MaaS API Key、Fay 凭据及其他密钥只能存放于受控密钥管理或未跟踪的本地配置，不进入 Git、前端 bundle、错误信息或日志。
- 对密钥实施最小权限、环境隔离、轮换和撤销；开发、演示、生产凭据不得复用。
- 服务管理接口和部署平台应实施身份认证与最小权限；CORS 来源限定到批准的前端域名。
- 外部请求启用 TLS；生产反向代理、证书更新和安全响应头由部署环境负责并记录。

## 4. 输入、模型和工具安全

- 对文本长度、格式、频率和资源消耗设上限；对高成本模型调用设置预算和速率控制。
- 把检索文档和用户输入作为数据而非指令，防御提示注入；系统约束不能被文档或用户文本覆盖。
- MCP 工具使用 allowlist、类型/schema 校验、超时、资源限制和最小权限；禁止模型拼接并执行任意 shell、SQL、Python 或浏览器脚本。
- RDKit 输入需限制大小、复杂度和处理时间；异常结构、安全错误应转换为受控错误状态。
- 前端只渲染经过 schema 校验的数据；转义用户内容，禁止直接执行模型返回的 HTML/JavaScript。
- 对模型输出的化学结论进行工具和来源校验；校验失败时降级为不确定性说明，不伪造安全性或正确性。

## 5. 依赖与供应链

- 生产发布需审查并锁定依赖版本，检查已知漏洞和许可证；当前 requirements 文件的最低版本范围不是完整锁定方案。
- RDKit、PyTorch、AutoAWQ、Transformers 与 CUDA 组合应在隔离环境构建并记录来源、版本和校验信息。
- 只从可信渠道获取 openPangu 权重，核验文件完整性、访问授权和使用条款；权重文件不应无控制地纳入公开仓库或镜像。
- 对构建产物、知识库备份和日志配置访问控制，建立备份恢复和凭据泄露应急流程。

## 6. 安全事件响应

发现密钥泄露时，立即撤销/轮换凭据，检查访问日志与账单，并清理泄露副本；不得仅从最新提交中删除而忽略 Git 历史和构建产物。发现错误知识或模型输出导致的教学风险时，保留必要的最小诊断信息，暂停受影响能力，撤回索引/模型配置并重新验收。

上线前需指定安全事件联系人、升级路径、服务暂停权限和通知要求。具体责任人与时限需由项目运营方补充。
