# 产品范围与验收标准

## 1. 产品定位

学智有机（Xuezhi-OrganicAgent）是面向高中有机化学学习的文本交互式 MCP 智能体教学系统，服务于课堂演示、课后探究和创新赛展示。核心目标是把高中课程范围内的反应机理解释、知识检索、分子结构展示和语音讲解组织成一条可追溯的学习体验。

本文描述目标产品行为。只有在对应功能完成实现、测试和验收后，才能对外宣称已提供。

## 2. 用户与主要任务

| 用户 | 主要任务 | 期望结果 |
| --- | --- | --- |
| 高中学生 | 询问有机物性质、反应条件和反应机理 | 获得符合高中课程范围的分步解释、依据和可视化结果 |
| 化学教师/演示者 | 展示典型反应并核对讲解内容 | 能重复演示、定位知识来源并发现模型不确定性 |
| 项目维护者 | 更新知识库、模型配置和运行服务 | 按变更记录、评估和回滚流程维护系统 |

## 3. 主要用户流程

1. 用户以文本描述问题或反应物、条件及目标。
2. 系统识别问题意图和缺失信息；必要时请求澄清，不凭空补足关键反应条件。
3. Agent 在授权工具范围内调用 RAG、化学解析/校验、分子可视化参数生成及讲解生成能力。
4. 系统返回机理文本、适用范围提示、可用的结构/动画数据和语音讲解状态。
5. 前端展示结果；用户可查看知识来源、重新提问或停止语音播放。

## 4. 范围内能力

- 高中有机化学文本问答，重点覆盖常见官能团、典型反应、条件和机理。
- 检索课程标准、教材、高考习题及经审核的术语资料。
- 通过 RDKit 对 SMILES 和分子结构进行解析、格式校验及适用的属性计算。
- 对具备可靠反应数据的场景生成结构变化和动画所需参数。
- 通过 Fay 与 Edge-TTS 相关服务呈现语音和数字人状态；外部服务不可用时，文本解释仍应可独立阅读。
- 云端 openPangu API 与本地 openPangu-7B-Instruct 两种模型运行模式。

## 5. 明确不在范围内

- 图片、手写公式、试卷照片或视频输入及图像识别。
- 以大学有机化学、无机化学、生物化学或离子反应为主要教学范围。
- 将语言模型输出视为实验事实、权威化学结论或安全操作指导。
- 在缺少可靠反应模板/数据时声称已完成严格的反应机理证明。
- 自动执行真实实验、控制实验设备或提供危险化学品制备指导。
- 保证网络服务、第三方模型、Fay 服务或 Edge-TTS 服务始终可用。

## 6. 回答质量要求

- 用高中生可理解的语言解释反应物、反应条件、主要产物和关键步骤。
- 区分检索到的课程事实、化学工具验证结果和模型生成的解释。
- 对超纲、条件不全、工具不支持或结果冲突的问题明确说明边界。
- 化学结构或反应未经工具验证时，不得把“模型生成”表述成“已校验”。
- 仅在存在可核对来源时附带来源信息；来源不可得时明确标注。

## 7. 验收基线

| 项目 | 验收要求 |
| --- | --- |
| 文本交互 | 支持中文文本提问；空输入、超长输入和服务超时有明确反馈 |
| 课程边界 | 对超出高中有机化学范围的问题给出边界说明，不伪装成确定答案 |
| 知识检索 | 答案来源可追踪到受控知识库条目，检索失败时不伪造引用 |
| 化学结构 | 无效 SMILES 或不支持结构不会触发误导性动画 |
| 反应解释 | 在已批准的测试集上由化学教师/领域审核者评估正确性与课程适配性 |
| 降级体验 | 非核心外部服务失败时，错误可理解，已有文本结果不被静默丢弃 |
| 双部署 | 云端与离线模式分别通过模型连通性、工具调用和代表性问答测试 |
| 隐私与安全 | 不在日志或客户端暴露凭据；对输入、工具和输出有基本安全检查 |

准确率阈值、延迟目标、可用性目标和硬件基准需由项目负责人依据实测数据另行批准，不在没有测试结果时预设数值。
