# 知识库内容治理

## 1. 目标与范围

知识库为高中有机化学问答提供经过筛选、版本化且可追溯的依据。优先内容包括现行课程标准、经授权教材、审核通过的高考习题及解析、受控化学术语对照表。具体教材版本、区域课程差异和版权许可需由项目负责人维护清单。

知识库不是化学事实的自动担保，也不应混入未标注的大学课程内容。知识库缺少答案时，系统应说明资料不足或请求补充条件。

## 2. 来源准入与元数据

每份源材料入库前应记录：

| 字段 | 说明 |
| --- | --- |
| source_id | 稳定且唯一的来源标识 |
| title / publisher | 标题、出版社或发布机构 |
| edition / published_at | 版本、发布日期或适用年份 |
| curriculum_level | 学段与课程范围，目标为高中 |
| topic / reaction_family | 知识主题或反应类别 |
| locator | 章节、页码、题号或原文位置（可获得时） |
| license / permission | 使用许可、授权范围和必要限制 |
| reviewer / reviewed_at | 审核人及审核时间 |
| status | 草稿、待审、已批准、已弃用或已撤回 |
| content_hash | 用于识别源文件变化的校验标识 |

无来源、授权状态不明、超纲或存在明显错误的内容不得进入生产索引。

## 3. 处理与审核流程

1. 登记来源及使用许可，保留原始文件和版本信息。
2. 提取文本并保留标题层级、表格、题号、反应条件及来源定位。
3. 清理页眉页脚等噪声；化学式、上下标、箭头、条件和异构体信息需人工抽检。
4. 按完整语义单元拆分，优先保持“概念/反应步骤/条件/例题/解析”上下文，不在关键条件中间截断。
5. 附加课程范围、主题、来源和审核元数据；执行超纲过滤和重复检测。
6. 由化学教师或指定审核者核对科学准确性、课程适配性、版权与来源定位。
7. 在隔离环境构建 ChromaDB 索引，使用固定 embedding 模型和参数运行检索评估。
8. 通过验收后发布带版本号的索引；保留前一可用版本及回滚记录。

不得在未记录 embedding 模型或切分参数变化的情况下复用旧向量。变更 embedding 模型时应完整重建索引并重跑评估。

## 4. 高中范围过滤

审核应重点识别：超出高中要求的机理细节、大学专有术语、未限定条件的过度概括，以及与当前课程标准不一致的表述。必要的拓展信息应明确标注为拓展内容，不应混入基础答案并被当作考试要求。

存在教材版本或课程区域差异时，保留差异说明及来源，不将不同版本内容简单合并成单一结论。

## 5. 检索和回答要求

- 检索结果应携带来源 ID、标题、版本、定位和审核状态。
- 检索排序和阈值需通过标注问答集实测确定，不使用未经评估的固定阈值。
- 仅将已批准且课程范围匹配的片段提供给模型。
- 回答中的可核验事实应能映射回检索片段；模型推断和工具计算需分别标识。
- 召回不足、来源冲突或反应条件缺失时，应拒绝确定性结论或发起澄清。
- 用户输入和外部文本都视为不可信数据，不允许其中的指令绕过系统/课程边界。

## 6. 评估基线

每次内容、切分、embedding 或检索参数变更前后，都使用版本化测试集比较：

- Recall@k、来源命中率和重复/冲突召回率。
- 课程范围准确性、知识点科学准确性和引用可追溯性。
- 无答案问题的拒答/澄清表现，以及错误确定性回答比例。
- 不同教材版本、题型、反应类别和条件缺失场景的覆盖情况。

测试集需包含高中范围内问题、超纲问题、错误前提、冲突资料、无依据问题和无效结构样例。数值门槛须根据基线测量及教学审核确定，不能以模型自评替代领域审核。

## 7. 版本、备份与撤回

每个已发布索引应关联源文件清单、处理版本、embedding 模型标识、切分参数、评估报告、审核记录和构建时间。定期备份原始资料与已批准索引；验证恢复过程。发现错误或授权撤销时，能够定位依赖该来源的索引版本并撤回或重建。
