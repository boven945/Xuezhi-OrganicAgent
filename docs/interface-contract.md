# 前后端逻辑接口基线

## 1. 文档性质

本文件定义前端、FastAPI 和 Agent 之间应共享的逻辑语义，用于实现前评审。当前仓库没有前后端源码或 API 实现，因此文中的字段是建议的语义字段，不是现存 JSON schema、URL、HTTP 方法或已发布 API。路由、版本号、鉴权、同步/流式/异步传输和字段必填性须在实现前通过 OpenAPI/schema 评审后确定。

## 2. 交互操作

| 操作 | 发起方 | 逻辑输入 | 逻辑输出 |
| --- | --- | --- | --- |
| 提交教学问题 | Web → API | 文本、可选会话标识、用户选择的展示偏好 | 请求关联标识及处理中/完成状态 |
| 获取教学答复 | API → Web | 问题处理结果 | 机理文本、课程边界/不确定性、可追溯来源、可选分子视图、可选语音状态 |
| 取消或结束请求 | Web → API | 请求/任务标识 | 取消是否受理；已完成请求须保持幂等结果语义 |
| 执行工具调用 | Agent → MCP 工具 | allowlist 工具名、经过校验的 schema 参数、关联标识 | 结构化结果或受控工具错误 |
| 请求语音/数字人 | Agent/API → Fay 适配 | 已审核的讲解文本、允许的语音/展示参数 | 音频或播放引用、数字人状态；具体数据传输协议待确认 |

是否需要独立取消接口、任务状态查询或 Fay 回调，取决于最终传输架构。

## 3. 答复语义字段建议

| 字段 | 建议语义 | 约束 |
| --- | --- | --- |
| request_id | 单次请求的可观测关联标识 | 不得承载个人信息或凭据 |
| status | 处理中、完成、部分完成或失败 | 使用稳定枚举并定义状态迁移 |
| explanation | 面向学生的机理解释 | 标明适用范围和必要的不确定性 |
| sources | 知识来源列表 | 包含 source ID、标题、版本和定位；无来源时为空，不伪造 |
| chemistry | 可选结构/计算结果 | 区分解析、规则校验和模型推断结果 |
| visualization | 可选渲染数据 | 使用经版本化 schema 的结构化数据，不接受可执行代码 |
| speech | 可选语音/数字人状态 | 外部媒体不可用时可缺省或标记不可用，不影响 explanation |
| error | 失败/部分失败详情 | 包含稳定错误码和安全用户文案；不得泄露堆栈或密钥 |

具体 JSON 类型、必填规则、大小限制和 schema 版本需在 OpenAPI 契约中定义，并由前后端共享验证。

## 4. 输入校验基线

- 仅接受 UTF-8 文本问题；限制字符数和请求体大小，实际阈值经性能与教学测试确定。
- 空文本、非法编码、格式错误、超频和不支持媒体输入应返回稳定且可理解的错误。
- 会话标识（如采用）应不可猜测、限期有效并与用户权限隔离。
- SMILES、反应条件或模型工具参数不能因出现在自然语言中而被默认信任；必须走各自 schema 和化学工具校验。
- 任何用户字段都不得用于拼接任意工具名、URL、文件路径或执行表达式。

## 5. 错误语义建议

实现应定义稳定的机器可读错误分类，至少覆盖：输入无效、超出课程/能力范围、模型不可用、知识检索不可用、化学结构无效/不支持、工具超时、速率限制、下游 Fay/TTS 不可用和内部错误。

错误响应需包含 request ID、可公开的简短说明及是否可重试（如适用）。内部堆栈只进入受控日志。部分失败应保留已成功的文本答案，并独立标明动画或语音未完成。

## 6. 兼容与版本策略

- 在实现前为 API 与可视化数据分别指定 schema 版本。
- 破坏性字段变更必须提升版本或提供兼容期，并同步更新前后端契约测试。
- 错误码、来源元数据和工具结果状态属于跨模块契约，变更需更新本文、OpenAPI 文件和回归测试。
- 本文不能替代机器可读 OpenAPI 文档；实现落地后应以经审查的 OpenAPI/schema 和契约测试为准。
